
# 🚗 Road Accident Analysis Dashboard

## 📌 Project Overview

The **Road Accident Analysis Dashboard** is an interactive Power BI project designed to analyze road accident data and identify important patterns related to **accident frequency, injuries, fatalities, time of occurrence, victim types, vehicle types, boroughs, and contributing factors**.

The dashboard transforms raw accident data into meaningful visual insights that can help understand accident trends, identify high-risk areas, and analyze the major factors associated with road accidents.

## 🎯 Objectives

* Analyze the overall number of road accidents, injuries, and deaths.
* Identify accident trends across different time periods.
* Compare accidents occurring on weekdays and weekends.
* Analyze injuries among pedestrians, cyclists, and motorists.
* Identify accident patterns by vehicle type and borough.
* Examine accident severity distribution.
* Analyze contributing factors associated with accidents.
* Identify areas and conditions that may require greater road-safety attention.

## 📊 Dashboard Pages

### 1. Executive Overview

Provides a high-level summary of the accident dataset through key KPIs and visualizations.

**Key insights include:**

* Total Accidents
* Total Injuries
* Total Deaths
* Safety Score
* Injuries by Vehicle Type
* Safety Score by Borough
* Accident trends over time

### 2. Time Analysis

Analyzes how accidents vary throughout the day and across different types of days.

**Analysis includes:**

* Accident trends by hour
* Weekday vs. weekend accidents
* Deaths by time of day
* Peak accident hour
* Accident count by day type
* Date-based filtering

### 3. Victim Analysis

Focuses on the different categories of people affected by road accidents.

**Analysis includes:**

* Pedestrian injuries
* Cyclist injuries
* Motorist injuries
* Injuries by victim type and borough
* Accident vs. injury comparison by borough
* Accident severity distribution
* Borough-level filtering

### 4. Root Cause Analysis

Uses Power BI's **Decomposition Tree** to investigate potential factors contributing to road accidents.

The analysis can be explored across:

* Borough
* Contributing Factor
* Vehicle Type
* Safety Score

This allows users to drill down into the data and explore possible relationships behind accident patterns.
